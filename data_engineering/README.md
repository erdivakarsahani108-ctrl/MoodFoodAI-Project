## 🌟 Overview

**AI Mood Based Vegetarian Food Recommendation System** is an intelligent, AI-driven web application that recommends personalized vegetarian meals based on your **mood**, **health metrics**, and **nutritional needs**. Built with modern web technologies, it leverages machine learning to analyze user data and provide actionable health insights.

> 🧠 *"Eat according to your mood, live according to your health."*

---

## ✨ Features

### 🎯 Core Features
- **Mood-Based Recommendations** – Get food suggestions tailored to your emotional state (Happy, Stressed, Energetic, etc.)
- **AI Health Insights** – Comprehensive health score, disease risk prediction, and nutrition analysis
- **Dashboard Overview** – Track health metrics, calories, protein, water intake, BMI, and sleep
- **Disease Wise Diet Plans** – Personalized diet recommendations for Diabetes, Heart Disease, Hypertension, Obesity, PCOD, and Kidney Disease
- **Weekly Meal Planning** – Generate weekly vegetarian meal plans based on your preferences
- **Nutrition Progress Tracking** – Monitor daily intake of calories, protein, fiber, and water
- **Mood History** – Visualize your weekly mood patterns with emoji-based tracking

### 🛠️ Admin Features
- **Food Management** – Add, edit, delete, and search food items
- **Disease Management** – Manage disease profiles and recommended foods
- **Mood Management** – Configure mood tags and emojis
- **User Management** – View and manage registered users
- **CSV Upload** – Bulk import food data via CSV files
- **Analytics Dashboard** – View platform statistics and user activity

### 🎨 UI/UX Highlights
- 🌓 **Dark/Light Mode** – Full dark mode support for comfortable viewing
- 💎 **Glassmorphism Cards** – Modern, sleek card design with blur effects
- 📱 **Fully Responsive** – Optimized for all screen sizes from mobile to desktop
- 🎨 **Beautiful Gradients** – Engaging color schemes with smooth transitions
- ✨ **Hover Animations** – Interactive elements with smooth micro-interactions
- 📊 **Progress Bars** – Visual tracking of daily health goals

## 🚀 Technologies Used

### Frontend
- **Next.js 14** – React framework with App Router
- **TypeScript** – Type-safe JavaScript
- **Tailwind CSS** – Utility-first CSS framework
- **Axios** – HTTP client for API communication
- **React Hooks** – State and effect management
- **Emoji Icons** – No external icon libraries needed

### Backend
- **FastAPI** – High-performance Python web framework
- **Python 3.11+** – Core programming language
- **SQLAlchemy** – ORM for database operations
- **JWT Authentication** – Secure token-based auth
- **Pydantic** – Data validation and serialization
- **Machine Learning** – Scikit-learn for recommendation algorithms

### DevOps & Tools
- **Uvicorn** – ASGI server for FastAPI
- **Pandas** – Data manipulation and analysis
- **NumPy** – Numerical computing
- **Pytest** – Unit testing framework
- **Docker** – Containerization (optional)
- **Git** – Version control
